`docs/lessons.md` に教訓を追記します。

## 確認事項

追記する前に、以下を自問してください:

- **コードや git log で分かることではないか？** → そうなら書かない
- **「何をしたか」ではなく「なぜそうしたか・次回どうすべきか」になっているか？**
- **同じ内容が既に書かれていないか？** → `docs/lessons.md` を読んで重複を確認

## フォーマット

```markdown
## YYYY-MM-DD <作業テーマ>

### <ハマりどころ・判断のタイトル>

<背景・何が起きたか（1〜3文）>

**→ <次回どうすべきか（1文の結論）>**
```

## 手順

1. `docs/lessons.md` を読んで既存の内容を確認する
2. 今回の作業で非自明だった判断・ハマりどころを特定する
3. 上記フォーマットで追記する
4. コミットに含める（PR に教訓を含めること）

$ARGUMENTS が指定されていれば、それをヒントに教訓の内容を生成してください。
指定がなければ、直近の git log と変更内容から教訓候補を提案してください。

```bash
git log --oneline -10
git diff HEAD~1 --stat
