description: docs/lessons.md に教訓またはミス記録を追記する
---

`docs/lessons.md` に教訓を追記します。記録の種類を判断してから書いてください。

## 記録の種類を判断する

**判断記録**（技術的なハマりどころ・非自明な選択）
→ 「なぜそうしたか・次回どうすべきか」が中心

**ミス記録**（ユーザーから修正・指摘を受けた場合）
→ 「何を間違えたか + 再発防止ルール」が必須。**ユーザー指摘後は必ずこちらを書く。**

## フォーマット

### 判断記録

```markdown
## YYYY-MM-DD <作業テーマ>

### <タイトル>

<背景・何が起きたか（1〜3文）>

**→ <次回どうすべきか（1文の結論）>**
```

### ミス記録

```markdown
## YYYY-MM-DD ミス: <テーマ>

### ミスのパターン

<何をどう間違えたか（具体的に）>

### 再発防止ルール

- <次回どう動けば防げるか（具体的なルール）>
```

## 追記前チェック

- コードや git log で分かることは書かない
- 「何をしたか」ではなく「なぜ・次回どうすべきか」になっているか
- 同じ内容がすでに書かれていないか（`docs/lessons.md` を読んで確認）

## 手順

1. `docs/lessons.md` を読んで既存の内容を確認する
2. 種類（判断 or ミス）を選ぶ
3. フォーマットに沿って追記する
4. コミットに含める

$ARGUMENTS が指定されていればそれをヒントに内容を生成してください。
指定がなければ、直近の git log・変更内容・ユーザーからの指摘履歴から候補を提案してください。

```bash
git log --oneline -10
git diff HEAD~1 --stat
```
